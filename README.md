# PJT_HaiAnGroup — Kho Lưu Trữ Dự Án Hải An Group

Kho lưu trữ tổng hợp các dự án phần mềm và ứng dụng của **Hải An Group (SuperHero1102)**. Mỗi dự án được đóng gói độc lập trong một thư mục riêng biệt để dễ dàng tải về, tái sử dụng hoặc mở trực tiếp trong **VS Code**.

## Danh Sách Dự Án

1. **[Loan_12_Su_Quan](./Loan_12_Su_Quan)** — **Loạn 12 Sứ Quân: Đinh Bộ Lĩnh Dẹp Loạn** (Game chiến thuật Match-3 RPG lịch sử Việt Nam, 13 Thẻ Tướng 3D, Hỗ trợ 100% Offline PWA v5 & Online, Giao diện Đồng Đông Sơn Hoàng Kim tràn viền).

## Hướng dẫn mở dự án Loan_12_Su_Quan trong VS Code
- Mở thư mục `Loan_12_Su_Quan` trong VS Code.
- Chạy `npm install` và `npm run dev` để khởi chạy môi trường phát triển, hoặc dùng ngay bản biên dịch sẵn trong `Loan_12_Su_Quan/dist/`.
