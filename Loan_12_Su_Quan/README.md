# Loạn 12 Sứ Quân — Đinh Bộ Lĩnh Dẹp Loạn (Loan_12_Su_Quan)

Dự án game chiến thuật đối kháng & hành quân lịch sử Việt Nam thuộc **Hải An Group**.

## Cấu trúc thư mục
- src/: Toàn bộ mã nguồn React + TypeScript + Giao diện Đồng Đông Sơn Hoàng Kim tràn viền 100%.
- public/: Toàn bộ hình ảnh 13 Thẻ Tướng 3D, bản đồ chiến dịch và Service Worker Offline PWA v5 (sw.js).
- dist/: Bản biên dịch thương mại sẵn sàng triển khai ngay.
